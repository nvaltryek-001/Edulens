# Reports and Guardian Notifications

## Class report
Approved SVIT logo/header; department/program/year/semester/section/group; subject and code; teacher; date/period/time/room; eligible/present/absent/review counts; student serial/USN/name/status/remarks; actual four stored classroom photos and timestamps; session/report ID; teacher verification; finalization timestamp; verification QR; correction history.

## Exports
PDF embeds actual evidence, never placeholders. Excel/PDF downloads enforce authorization. Use private storage and short-lived authorized links or controlled generation. Log sensitive access. Never expose embeddings or internal similarity values in ordinary reports. Never send a whole-class report to a guardian.

## Notifications
Only verified guardians, after official finalization and confirmed absence. Integrate an institution-approved email/SMS/WhatsApp Business provider. Track queued/sending/accepted/delivered/failed only as supported by provider evidence. A successful request is not proof of delivery.

Use idempotency, bounded exponential retries, duplicate suppression, failure visibility, correction notifications where policy requires, and audit trail. Minimize personal information and validate active guardian-ward links.
