# EduLens – Digital Facial Recognition Attendance System

EduLens is an advanced facial recognition attendance management system designed to recognize multiple students simultaneously from a single classroom photograph.

## Features
- **Administrator Module**: Register students, manage dataset, and view reports.
- **Teacher Module**: Capture classroom image, auto-detect faces, recognize students, and record attendance.
- **Local AI Module**: Uses MediaPipe Face Detection and Face Mesh for geometric facial embeddings, classified by a Random Forest model. Runs entirely locally without paid APIs.
- **Android App**: Kotlin, Jetpack Compose, CameraX, Room database, Retrofit.
- **Backend API**: Python, Flask, SQLite, JWT Authentication.
