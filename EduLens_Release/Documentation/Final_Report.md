# EduLens Final Project Report

**Project Name:** EduLens – Attendance Tracking System Using Facial Recognition
**Institution:** Sai Vidya Institute of Technology (SVIT)

## Overview
EduLens is a robust attendance tracking system that leverages modern computer vision to automate classroom attendance.

## Features
- Real-time face detection
- Secure backend API
- Mobile-first Android interface
- Automated model retraining

## Testing
- All endpoints tested successfully.
- Android application built (APK generated).
- Machine learning pipeline validated with mock embeddings.
